# SQL

Aqui entram os scripts do projeto, na ordem em que são produzidos:

1. `01_perfilamento.sql`: consultas que acham os problemas de qualidade nos arquivos legados.
2. `02_staging.sql`: criação das tabelas de staging.
3. `03_limpeza.sql`: regras de limpeza, com registro das linhas rejeitadas e do motivo.
4. `04_reconciliacao.sql`: contagens e totais de controle entre origem, staging e destino.

Cada script entra no repositório quando eu o termino, e a data do commit mostra quando.
